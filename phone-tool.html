Phone Number Replacer

Upload a ZIP → scans all text files (HTML, JS, CSS, JSON, etc.) for phone numbers → replace them → download the updated ZIP or push to GitHub.

Drop your .zip here, or click to browse

Every text file inside (any folder) is scanned — HTML, JS, CSS, JSON, TXT… Binary files (images, fonts, media) are skipped.

Push to GitHub

Commits all files from the zip (with numbers replaced) directly to the branch, at the repo root. Needs a token with Contents: Read & Write on the repo.

🔑 Uses the dashboard's GitHub token automatically — no token needed.
